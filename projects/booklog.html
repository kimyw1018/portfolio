독서 기록 앱: Book Log → bookieOn

캘린더 기반 독서 기록 앱의 Android 네이티브 구현과 웹 SPA 마이그레이션

읽은 책의 페이지·별점·감상평을 캘린더에 기록하는 독서 습관 앱입니다. Phase 1은 Android(Java) 네이티브로 직접 만들었고, Phase 2에서는 같은 Firestore 데이터 스키마를 그대로 이어받아 React 19 + TypeScript 웹 SPA bookieOn으로 혼자 마이그레이션해, iOS·PC 브라우저 사용자도 접근할 수 있게 하고 비동기 발제 토론 기능을 더했습니다.

03Phase 2 — 웹 SPA 마이그레이션 (bookieOn)

기존 안드로이드 화면을 13개 라우트의 반응형 웹 SPA로 100% 이식했습니다 (PR #1).

01

Firestore Prefix Range Query 검색: Firestore에는 SQL의 LIKE '%keyword%'가 없어, 유니코드 Private Use Area 문자 U+F8FF가 거의 모든 출력 문자보다 뒤에 정렬된다는 특성을 이용해 where("name", ">=", keyword)와 where("name", "<=", keyword + "\uF8FF") 복합 조건으로 "시작하는 문자열" 검색을 단일 인덱스 스캔으로 구현했다.

02

TanStack Query 정밀 캐시 무효화: 모든 쿼리 키를 로그인 사용자 uid로 격리(["feedItems", user?.uid] 등)하고, 독서 기록 수정 시 홈 피드 캐시와 개별 기록 상세 캐시를 함께 타겟 무효화해 데이터 정합성을 보장했다.

03

월별 캘린더 그리드 + O(1) 날짜 조회: 요일 오프셋과 월 일수로 7열 캘린더 셀 배열을 생성하고, 전체 독서 기록을 매 렌더링마다 순회하는 대신 useMemo로 날짜 문자열을 키로 하는 Map<string, FeedItem[]>을 만들어 O(1) 조회로 바꿨다. 무거운 캘린더 라이브러리 없이 순수 Date 객체와 CSS Grid로 구현해 번들 크기도 줄였다.

04Problem Solving
01

Cloudflare 정적 호스팅에서 SPA 새로고침 404: /group, /calendar 같은 하위 라우트에서 직접 URL 진입이나 새로고침을 하면 서버가 실제 파일을 찾지 못해 404를 반환했다. HashRouter(/#/group)는 URL에 #이 노출되어 미채택, Cloudflare Pages 전용 _redirects 파일은 Workers 프로젝트에서는 무시되어 일시 채택 후 폐기했다. 최종적으로 wrangler.jsonc에 다음 설정을 추가해 해결했다: 

{
  "name": "bookieon",
  "compatibility_date": "2026-09-01",
  "assets": {
    "directory": "./dist",
    "not_found_handling": "single-page-application"
  }
}
