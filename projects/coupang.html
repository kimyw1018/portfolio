Backend Scheduler • 2025 • Node.js / TypeScript

쿠팡 WING 쿠폰 자동 갱신 스케줄러

당일 즉시할인 쿠폰 자동 갱신 & 무중단 장애 모니터링

쿠팡 WING Open API를 연동하여 당일 즉시할인 쿠폰을 매일 정해진 시각에 자동으로 롤오버 갱신하고, API 실패 시 실시간 장애 알림을 전송하는 서버 사이드 스케줄러입니다.

TypeScript (v5.5+)Node.js (v20+)AxiosCrypto (HMAC-SHA256)Discord WebhookScheduler

담당 역할 및 범위

TypeScript 서버 사이드 백엔드 스케줄러 및 Open API 연동 파이프라인 개발

보안 및 인증 아키텍처

Node.js 내장 crypto 모듈을 활용하여 쿠팡 WING Open API 규격 HMAC-SHA256 서명(Signature)을 자체 생성 (외부 종속성 제로 달성)

dotenv 기반 환경변수 Fail-Fast 검증: 기동 시 필수 API Key/Secret 누락 여부를 선제 검증하여 런타임 크래시 방지

배치 파이프라인 및 장애 격리(Fault Isolation)

3단계 쿠폰 롤오버 라이프사이클: 기존 쿠폰 목록 조회 -> 루프 기반 안전 폐기 -> 당일 기준 신규 쿠폰 KST 발행

개별 쿠폰 처리 실패 시에도 전체 배치가 중단되지 않는 예외 격리 및 실패 항목 선별 로깅

다중 계약 ID 폴백 전략 (환경변수 -> 목록 API 캐시 -> 단일 API 폴백)

Discord Webhook 실시간 알림: 장애 발생 위치 및 에러 스택 트레이스를 정형화된 Embed 카드로 즉시 전송
