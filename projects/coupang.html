쿠팡 WING 쿠폰 자동 갱신 스케줄러

당일 즉시할인 쿠폰 자동 갱신과 무중단 장애 모니터링

쿠팡 WING Open API로 당일 즉시할인 쿠폰을 정해진 시각에 자동 롤오버하고, 실패 시 실시간으로 알리는 서버 사이드 스케줄러입니다.

TypeScript (v5.5+)Node.js (v20+)AxiosCrypto (HMAC-SHA256)Discord WebhookScheduler
01Role
TypeScript 서버 사이드 스케줄러와 Open API 연동 파이프라인 개발을 전담했습니다.
02Security
01

Node.js 내장 crypto 모듈로 쿠팡 WING API 규격의 HMAC-SHA256 서명을 직접 생성해 외부 의존성을 없앴다.

02

dotenv 기반 환경변수 검증으로 기동 시 필수 API Key와 Secret 누락을 먼저 확인해 런타임 크래시를 막았다.

03Pipeline
01

기존 쿠폰 조회, 루프 기반 안전 폐기, 당일 신규 쿠폰 발행 순서로 3단계 롤오버 파이프라인을 구성했다.

02

개별 쿠폰 처리가 실패해도 전체 배치가 멈추지 않도록 예외를 격리하고 실패 항목만 따로 기록했다.

03

환경변수, 목록 API 캐시, 단일 API 순서로 이어지는 다중 계약 ID 폴백 전략을 만들었다.

04

Discord Webhook으로 장애 위치와 에러 스택을 즉시 카드로 전송해 장애를 바로 확인할 수 있게 했다.
