Backend Repository Android Repository

📌 프로젝트 개요 및 담당 역할

담당 업무: 학생-매장 간 제휴 서비스의 매장 순위 및 통계 시스템 구현, 파트너 매장 실시간 순위 추적 및 사용량 분석 기능 구현, 관리자용 통계 시스템과 데이터 시각화 통합, 백엔드 API 설계부터 Android 클라이언트 구현까지 풀스택 전담.

📱 Part 1. [Android] 대시보드 클라이언트 구현

주요 기술적 기여

  • 타입 안전 상태 관리 시스템: Sealed Interface 기반 Exhaustive State Management 및 StateFlow 반응형 아키텍처로 런타임 상태 에러 0건 달성 및 UI 깜빡임 제거
  • Clean Architecture 멀티 레이어: Presentation / Domain / Data 레이어 완전 분리, Repository + UseCase 패턴 적용으로 비즈니스 로직 캡슐화
  • 병렬 API 호출 최적화: Kotlin Coroutines async/await를 활용해 독립적인 3개 API 동시 호출 및 coroutineScope 부분 실패 방어
  • Retrofit + Hilt 네트워크 계층: Moshi JSON 직렬화, SharedPreferences 토큰을 주입하는 AuthInterceptor, Hilt 모듈 분리 구성

안드로이드 트러블 슈팅 (Deep Dive)

• ViewModel 상태 불일치 에러:

Sealed interface와 data class 간 이름 중복 정의로 발생한 컴파일 에러를 독립 타입 분리 및 getCurrentData() 헬퍼 함수 구현으로 컴파일 타임에 모든 상태 처리를 강제함.

• MPAndroidChart UI 미반영 동기화 문제:

주차 선택 시 차트 색상이 갱신되지 않던 이슈를 Fragment의 StateFlow Observation 추가 및 invalidate() 연동, 둥근 모서리 커스텀 렌더러(RoundedBarChartRenderer) 적용으로 해결.

⚙️ Part 2. [Spring Boot] 백엔드 API & 클라우드 인프라

주요 기술적 기여

  • 도메인 모델 & 통계 집계 최적화: Student-Store 관계 정규화 및 CTE, RANK() OVER Window Function으로 주간 순위 단일 쿼리 일괄 집계 (복합 인덱스 설계로 O(N) → O(log N) 개선)
  • 공간 인덱싱(GIS) 지도 최적화: WKT 뷰포트 변환 후 PostGIS R-Tree 인덱스로 공간 바운딩 박스 필터링만 DB에 전담시키고, 권한 검증은 WAS 메모리(HashSet O(1))로 분리하여 DB CPU 병목 완화
  • 비관적 락(Pessimistic Lock) 동시성 제어: 제휴 사용량 동시 업데이트 시 집계 누락(Lost Update) 방지를 위해 SELECT ... FOR UPDATE 행 단위 잠금 적용
  • K3s 기반 GitOps 파이프라인: GitHub Actions → Manifest 저장소 커밋 → ArgoCD 3-Node 클러스터 자동 반영(selfHeal) 및 Git Submodule 민감 설정 격리

백엔드 & 인프라 트러블 슈팅 (Deep Dive)

• 공간 쿼리 DB CPU 과부하 및 N+1 문제:

대용량 공간 연산과 다중 JOIN 병목을 해소하기 위해 공간 필터링(PostGIS)과 비즈니스 권한 검증(WAS 메모리)을 분리하고 하위 데이터는 IN 절 Bulk Read + Stream groupingBy로 쿼리 1회 최적화.

• STOMP 실시간 메시징 시 SecurityContext 누락:

ThreadLocal 컨텍스트가 WebSocket 비동기 스레드 풀로 전파되지 않는 문제를 분석하여, CONNECT 시점에 이미 JWT가 검증되는 프로토콜 수명주기를 파악하고 중복 검증을 제거해 컨텍스트 복사 오버헤드 해소.

• Flannel VXLAN 8472 UDP 프로토콜 오설정 복구:

AWS 보안그룹에서 Flannel VXLAN 포트 8472를 TCP로 열어 노드 간 파드 통신 타임아웃이 발생하던 문제를 UDP로 수정하여 오버레이 통신 정상화.
