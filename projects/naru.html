05Problem Solving
Edge AI 30fps 온디바이스

무거운 LSTM 추론을 버리고 DTW 템플릿 매칭으로 전환한 이유

추론 지연을 없애고, 사용자가 자기만의 수어 단어를 즉시 등록할 수 있게 만들기 위해서다.

문제

초기 프로토타입은 30프레임 시계열을 LSTM으로 브라우저에서 추론(ONNX.js / TensorFlow.js)했다. 보급형 랩탑과 모바일 브라우저에서는 추론 지연 때문에 30fps를 유지할 수 없었고, 사용자가 자기 수어 단어를 새로 등록하기도 어려운 구조였다.

해결

신체 기준으로 정규화한 궤적을 실시간 비교하는 경량 DTW(Dynamic Time Warping) 템플릿 매칭으로 바꿨다. 가중치 연산 없이 동작 속도 차이를 보정하면서 브라우저 안에서 30fps로 인식하고, 사용자가 화면에서 10초 만에 새 단어를 등록할 수 있게 했다.

결과: 브라우저 온디바이스 30fps, 사용자 맞춤 단어 등록 지원
Computer Vision 공간 불변성

카메라 거리와 위치에 따라 좌표가 왜곡되는 문제

절대 픽셀 좌표 대신 어깨 중심 기준 상대 좌표로 바꿔서 해결했다.

문제

사용자가 카메라에 가까이 다가가거나 화면 한쪽으로 치우치면 절대 픽셀 좌표가 크게 왜곡됐다. 등록된 동작과 똑같이 움직여도 DTW 거리 값이 커져서 인식이 실패했다.

해결

MediaPipe Pose의 양쪽 어깨 중점을 원점 (0, 0, 0)으로 옮기고, 어깨 사이 거리를 단위 길이 1.0으로 두어 모든 손 랜드마크를 스케일링했다. 신체 상대적 정규화로 거리나 위치가 바뀌어도 좌표계가 흔들리지 않게 만들었다.

결과: 거리·화각이 바뀌는 환경에서도 인식률 95% 이상 유지
Interaction 오인식 차단

순간적인 오인식과 발화 종료 시점 판별 문제

연속 프레임 검증 가드와 손 내림 감지 버퍼로 정리했다.

문제

조명 변화나 손 떨림으로 특정 프레임에서 순간적으로 오인식이 발생했고, 사용자가 동작을 마친 뒤 언제 문장 변환을 시작할지도 애매했다.

해결

동일 후보 단어가 5프레임 이상 연속으로 매칭될 때만 후보 큐에 등록해 튐 노이즈를 걸렀다. 손을 내리는 제스처를 감지하고 1.5초간 추가 수어가 없으면 발화 완료로 보고, 수집된 단어 시퀀스와 직전 12턴 대화 히스토리를 LLM에 넘겨 자연스러운 구어체 문장으로 바꿨다.

결과: 오발송 제로화, 끊김 없는 양방향 대화
