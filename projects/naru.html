3. 핵심 기능 및 아키텍처 (Key Features & Architecture)

1. 브라우저 온디바이스(Client-Side) 실시간 수어 인식 파이프라인

  • MediaPipe 기반 3D 랜드마크 추출: WASM 및 WebGL GPU 가속을 활용해 손 21개 랜드마크 및 상체·어깨·팔 포즈 좌표를 30fps 속도로 추출
  • 신체 상대적(Body-relative) 3D 정규화: 양 어깨 중심점과 너비를 기준으로 좌표계를 재설정하여 사용자 거리·위치 변동에 강건한 데이터 가공
  • 경량 DTW(Dynamic Time Warping) 매칭: 30프레임 롤링 윈도우 시퀀스를 기반으로 동작 속도 차이(Time-Warping)를 보정해 정확한 수어 단어 분류

2. 맥락 인지형 LLM 문장 변환 (Sign Gloss → Natural Korean)

  • 발화 완료 감지: 손을 내리는 제스처를 감지하는 버퍼 시스템을 통해 발화 종료 시점을 판별
  • 대화 맥락 반영 구어체 합성: 직전 최대 12턴의 대화 히스토리를 LLM에 전달해 단순 단어 나열이 아닌 자연스러운 한국어 문장으로 생성

3. 사용자 맞춤형 10초 케이던스 단어 등록 시스템

  • 케이던스 바(Cadence Bar) UI: 10초간 2초 주기로 10회 레퍼런스 샘플을 분할 캡처하는 직관적 가이드 제공
  • 인메모리 고속 캐싱: 등록된 커스텀 수어 데이터를 클라이언트 마운트 시 캐싱하여 런타임 네트워크 오버헤드 없이 온디바이스 매칭 수행

4. 실시간 WebRTC 통화 및 청각장애인 특화 접근성

  • 전화 라이프사이클 관리: 번호 기반 발신, 인커밍 폴링(3초), 하트비트 세션 임대(10초)를 연결한 상태 머신 구축
  • 하이브리드 커뮤니케이션: PiP 수어 영상 모드, 음성 모드, 텍스트 채팅 모드를 단일 타임라인(useTimeline)으로 통합 제어
  • 모바일 접근성 인터랙션: iOS Safari 진동 피드백(ios-haptics) 및 Web Audio API 기반 DTMF 다이얼 톤 구현, 당근 SEED Design 토큰 기반 고대비 UI

4. 문제 해결 및 트러블 슈팅 (Deep Dive)

Issue 1

무거운 시퀀스 분류 모델 한계 극복 → DTW 매칭 전면 피벗

문제: 초기 30프레임 LSTM 신경망 모델 구동 시 브라우저 추론 지연 및 메모리 부담이 컸고, 새로운 수어 단어를 동적으로 추가하기 어려운 구조적 한계 봉착

해결: 신체 기준 정규화 랜드마크 궤적을 비교하는 고속 DTW(Dynamic Time Warping) 알고리즘으로 전환하여 브라우저 온디바이스 연산 100% 달성 및 실시간 커스텀 단어 등록 지원

Issue 2

사용자 거리 및 위치 변화에 따른 인식률 저하

문제: 카메라와의 거리나 좌우 위치 이동 시 절대 좌표 왜곡으로 동일한 동작임에도 DTW Distance가 급증하는 문제 발생

해결: 양쪽 어깨 중점을 원점 (0, 0, 0)으로 재설정하고, 어깨 간 거리를 단위 스케일(1.0)로 정규화하는 전처리 알고리즘을 적용하여 공간 불변성(Spatial Invariance) 확보

Issue 3

발화 종료 감지 타이밍 및 턴 테이킹 최적화

문제: 발화 종료 판별 지연(초기 3초)으로 대화 템포가 늘어지고, 순간적인 프레임 튐 현상으로 오발송 발생

해결: 대기 시간을 1.5초(HANDS_GONE_FLUSH_MS)로 단축해 체감 속도 대폭 개선, 동일 후보 단어가 5프레임 이상 유지될 때만 확정하는 REQUIRED_STREAK = 5 및 손을 내렸을 때 리셋하는 가드 로직 구축

Issue 4 & 5

커스텀 단어 녹화 타이밍 및 미디어 트랙 누수 방지

해결: 2초 주기 시각 가이드를 제공하는 케이던스 바(Cadence Bar)로 5프레임 미만 비정상 세그먼트를 자동 스킵하고, 통화 종료 시 mediaStream.getTracks().forEach(t => t.stop()) 클린업과 세션 스토리지 즉시 초기화로 카메라 점유 누수 방지
